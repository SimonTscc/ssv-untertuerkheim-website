# SSV Untertürkheim – Website

Neu gebaute, moderne Website für den **Sportschützenverein Stuttgart-Untertürkheim e.V.** (SSV Untertürkheim), gegründet 1930, ansässig in der Dietbachstraße 38, 70327 Stuttgart.

Eigenständiges Projekt, inhaltlich recherchiert auf Basis der bisherigen Vereinswebsite (Geschichte, Disziplinen, Jugendarbeit, Preise, Öffnungszeiten, FAQ) und als einzelne, selbstständige `index.html` (kein Build-Prozess, keine Abhängigkeiten) neu umgesetzt.

## Struktur

- `index.html` – komplette Website (Hero, Über uns, Schießsport/Disziplinen, Jugend, Preise, Kontakt/Öffnungszeiten, FAQ, Footer)

## Nutzung

Einfach `index.html` im Browser öffnen, oder über GitHub Pages hosten:
Settings → Pages → Branch `main` → Ordner `/ (root)`.

## Noch zu ergänzen

- Funktionierendes Kontaktformular-Backend (aktuell `mailto:`-Fallback)
